# Homebrew tap de AllForMonitors

Recetas de [Homebrew](https://brew.sh) para [AllForMonitors](https://github.com/Diegoafigue/AllForMonitors-releases), la app de barra de menú para controlar monitores externos en macOS.

*Homebrew casks for AllForMonitors, the menu bar app to control external monitors on macOS.*

## Instalar / Install

```bash
brew install --cask diegoafigue/tap/allformonitors
```

La receta llega con la primera beta. / *The cask arrives with the first beta.*

## Actualizar / Update

La app se actualiza sola. Para hacerlo con Homebrew:
*The app updates itself. To do it with Homebrew:*

```bash
brew upgrade --cask --greedy allformonitors
```

## Desinstalar / Uninstall

```bash
brew uninstall --cask allformonitors
```

Con `--zap` también se borran sus ajustes. / *Add `--zap` to remove its settings too.*
